# Phase 1.1.0 Log — Project Bootstrap

## Phase
- **Number:** 1.1.0
- **Name:** Project bootstrap (Xcode project, core package, CI, empty app shell)
- **Status:** Completed
- **Date completed:** 2026-09-26

## Phase Goal
Create the iPad app and a verification path despite a Linux-only development container: a generated
`.xcodeproj` with synchronized folders, a Linux-testable core package, and macOS CI as the compiler of record.

## Major Additions
- `Tools/gen_xcodeproj.py` — deterministic generator for `Koubutsu.xcodeproj/project.pbxproj` and the shared scheme (objectVersion 77, `PBXFileSystemSynchronizedRootGroup` for `App/` and `AppTests/`, local package `Packages/KoubutsuCore`).
- `App/KoubutsuApp.swift`, `App/UI/RootView.swift` — SwiftUI shell.
- `AppTests/AppSmokeTests.swift` — Swift Testing smoke test hosted in the app.
- `Packages/KoubutsuCore` — Swift 6 package, `CoreInfo`, smoke test.
- `.github/workflows/core-linux.yml` (swift:6.2 container) and `.github/workflows/ios.yml` (macOS runner: Xcode select, SDK report artifact, simulator build+test).
- `Tools/ci_select_xcode.sh`, `Tools/ci_simulator_test.sh`, `Tools/sdk_report.sh`.

## Major Changes
- The pbxproj is generated by a script rather than hand-edited so IDs are deterministic and settings are reviewable in one place.
- Core enum renamed `CoreInfo` to avoid module/type name shadowing (`KoubutsuCore.KoubutsuCore`).

## Progress Made
- First CI run green on both workflows (commit 533d663): the generated project builds and its tests pass on an iPad simulator.
- CI facts: runner image macos-26-arm64, Xcode 26.6, iOS SDK 26.5, iOS simulator runtimes 26.2/26.4/26.5, M5/M4/A16/A17 Pro iPad simulators.

## Key Decisions
- Swift Testing in both the package and the app test target.
- Deployment target left provisional at 18.0 for this phase; finalized in 1.1.1.

## Current Limitations

- The first SDK report truncated the Vision Swift API section; fixed in 1.1.1.
