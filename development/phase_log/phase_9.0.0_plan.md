# Phase 9.0.0 Plan — UI polish: the Koubutsu look (umbrella)

## Phase
- **Number:** 9.0.0
- **Name:** Definitive visual identity — Heisei-era VCR/surveillance-HUD pixel style
- **Status:** Planned
- **Date drafted:** 2026-09-26

## Purpose
Give Koubutsu a unique, consistent style instead of stock iOS controls: late-90s/2005 Heisei Y2K print and VCR
on-screen-display aesthetics (paper white, ink black, signal red, dithered 1-bit imagery, detection boxes, corner
ticks, monospaced OSD type), from the user's references.

## Immediate Goal
Ship 9.1.0–9.3.0 below; every standard control the user touches is a Koubutsu component.

## Confirmed Starting Point
Major 8 complete (`9c4d3d9`). Stock SwiftUI controls, SF Symbols, no asset catalog, no custom font.

## Scope For This Phase
### In
- Font: VCR OSD Mono (Riciery Leal, dafont "100% free") for Latin UI text; Japanese keeps the system font.
- Palette/tokens, type scale, textures (grain, scanlines, dither) and components: buttons, icon buttons,
  toggles, sliders, segmented pickers, custom menus (replacing `Menu`), panels, tags, section headers, sheets.
- Original pixel art generated by `Tools/pixel_art.py`: icon set, logo, app icon, cover art.
- A few smooth animations in easy places (boot, freeze, selection, panels, presses), Reduce Motion aware.
### Out
- Third-party art: the supplied "Cyber Sigils" pack has no licence file and the repository is public, so it
  is not redistributed. System file pickers/share sheets and the iPadOS dictionary stay system UI.

## Technical Plan
Roadmap checklist:
```
- [ ] 9.1.0 — Design system + pixel art: tokens, VCR OSD Mono/DotGothic16, textures, components (KButton,
              KIconButton, KToggle, KSlider, KSegmented, KMenu, panels, tags, headers, sheets), UIKit appearance;
              icon set, logo mark + wordmark, app icon, launch screen, cover art (Tools/pixel_art.py)
- [ ] 9.2.0 — Retheme every screen: control/transport bars, panels, overlays, study view/panel, word card,
              word bank, review, settings, recent lines
- [ ] 9.3.0 — Animations: boot sequence, freeze scan + OSD stamp, selection bracket snap, stepped panel
              reveals, press feedback, blinking cursor
```

## Test Plan
CI iOS build/tests and simulator screenshots for every screen; core tests unaffected.

## Key Decisions
- Paper-white sheets with ink text and red accents (poster look); black chrome around the video (VCR look).
- Pixel art is drawn as grids in code and scaled with nearest-neighbour so it is original, reproducible and crisp.

## Expected Limitations At End Of Phase
- VCR OSD Mono has no kana/kanji; Japanese text uses the system font beside it.

## What Comes Next
- 9.1.0.

## Summary
Koubutsu looks like nothing else on the iPad: a Heisei VCR surveillance console for reading Japanese.
